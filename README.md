# Wine Quality Prediction

## Project Overview
This project predicts wine quality using Machine Learning techniques based on physicochemical properties such as acidity, alcohol content, pH, sulphates, and density.

## Dataset
- Wine Quality Dataset
- Features include acidity, residual sugar, chlorides, alcohol, pH, sulphates, etc.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Model
- Random Forest Classifier

## Workflow
1. Data Loading
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature Selection
5. Model Training
6. Model Evaluation
7. Wine Quality Prediction

## Results
The model was trained and evaluated using train-test split and achieved reliable prediction performance.
